ISP 2024

Raw source data

The ISP report catalogue lists the configured report collections for both editions and the reports with an explicit counterpart. The ISP 2024 source-data reference lists files, workbook selections, keys, fields, and units. The workbook and trace structure describes workbook selections, scenario models, trace folders, and trace schemas. The source-material guide groups the 2024 and 2026 workbooks by subject. The shared trace coverage page compares trace families, reference-year terminology, schemas, and PoE material.

Compare editions

The raw-source comparison compares worksheet additions and removals, source-family moves, declared worksheet dimensions, and schema changes. The model archive comparison compares scenario directories, model files, trace families, and archive packaging. The comparison guide links the report, workbook, trace, and mapping comparisons.

ParseISP 2024 workflow

ParseISP implements a data-construction workflow for the 2024 Integrated System Plan. ParseISP.build_ISP24_datasets reads the supported inputs, applies the package's parsers and mappings, and writes static asset tables and time-varying schedule tables.

New users should begin with the Quickstart to install ParseISP.jl, build one short date range, and check representative outputs. The preprocessing workflow explains source preparation, static construction, schedule overlays, optional build-outs, and output writing. The output tables page defines the generated dataset and its joins. The parameters and mappings page records package-defined conventions that affect interpretation.

Reading the generated data

The static tables describe assets and their comparatively stable attributes. The schedule tables describe selected quantities that vary by scenario and time. Interpret a schedule alongside the corresponding static table and its scenario and date fields rather than as a standalone asset inventory.

The working with ParseISP-generated outputs tutorial demonstrates this relationship with a selected 2024 build. The validation and analysis sections of the ISP 2024 documentation provide release-specific checks and exploratory context for those sources and outputs.

Scope

The 2024 workflow is a data-preparation step for downstream power-system studies. It does not itself run dispatch, unit commitment, capacity expansion, or power-flow models. See assumptions and scope before treating generated data as study-ready.
